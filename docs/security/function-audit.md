## Classification Categories

- **Category A**: Trigger / Internal only (Must NOT be callable via API)

- **Category E**: Server / Cron only (Scheduled maintenance; restricted strictly to service_role)
- **Category F**: Test-only fixtures (Moved to `test_support` schema; unexposed to public API)
